# Syed Ukasha Shahid: Slide Portfolio

One page, one fixed screen, six slides. Plain HTML, CSS and JavaScript. No libraries, no build step.

## Run it
1. Keep the folder together (index.html, style.css, script.js, assets/).
2. Double-click `index.html` to open it in Chrome, Edge or Firefox.

## Files
- `index.html`: the six slides, header and footer
- `style.css`: layout, theme, transitions
- `script.js`: slide controller, arrow keys, Copy Email
- `assets/Syed_Ukasha_Shahid_Resume.pdf`: your real CV (used by Download CV)

## Built
Six slides from your CV, fixed viewport layout, animated nav indicator, slide counter, arrow-key navigation, reduced-motion support, Download CV link, mailto and tel links, Copy Email with success or failure message.
